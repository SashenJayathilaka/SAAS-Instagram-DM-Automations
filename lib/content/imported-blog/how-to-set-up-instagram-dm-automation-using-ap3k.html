AP3K automates eligible Instagram conversations. This guide walks through connecting your professional Instagram account, selecting a post, and testing a comment-to-DM automation. Facebook Messenger automation is not part of this setup.

Connect your Instagram account

Create an AP3K account, choose Add Instagram account, and complete Instagram authorization. Use a Business or Creator account and approve the permissions needed for comments and messages. Return to the dashboard and confirm the connection is ready.

Choose a post or Reel

Open Automations and create a comment automation. Select the Instagram post or Reel that should start the conversation. Use a post with a clear offer, such as a guide, product link, booking page, or pricing sheet.

Set your trigger

Choose a keyword such as LINK or PRICE, or select Any comment when every eligible comment should match. Keep the caption consistent with the trigger. If you enable the share trigger, check that you selected the intended post. Use One DM per user when repeat comments should not send another opening message.

Write the response

Choose a public reply, a DM, or both. Write a short message that explains what the person will receive. Add your destination URL and a clear button label. Review the phone preview and any optional opener, follow request, or information collection step. Paid features require an eligible plan when publishing.

Review timing and follow-ups

If your campaign includes a delay or follow-up, review its settings and delivery readiness before publishing. Messages remain subject to Meta's allowed messaging window. A longer delay does not grant permission to contact someone outside that window.

Publish and test

Publish the automation, then use a different Instagram account to leave a matching comment. Check both the public reply and DM, open the link, and review activity in AP3K. Test non-matching comments too. If a response is missing, check connection permissions, the selected post, trigger text, and remaining usage in Billing.
