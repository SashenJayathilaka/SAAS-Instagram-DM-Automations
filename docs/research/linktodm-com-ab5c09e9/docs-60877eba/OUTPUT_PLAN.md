# Documentation output plan

Source: https://linktodm.com/docs/ and its 77 observed article routes.
Destination: /docs and /docs/[...slug], replacing LinktoDM names in slugs with ap3k.
Repository: AP3K existing application; retain existing blog and all product routes.
Existing /help routes become redirects to their equivalent documentation pages. In-app help remains available.
Use scoped components/docs and lib/docs; public/images/docs contains real AP3K screenshots only. No generated product UI.
Shared foundation: documentation types, article loader and route-scoped CSS. Existing global styles are not replaced.
Source text is adapted to actual AP3K capabilities and branding. Unsupported Facebook, Zapier, MCP, Backtrack, and any unsupported nodes must not be presented as available features.
Embed user tutorial SSOYGbfwLUQ with responsive, privacy-enhanced YouTube loading; no autoplay.
Remove launch-kit signup from blog and resource pages. Preserve existing unsubscribe/consent processing.
