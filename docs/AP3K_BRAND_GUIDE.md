# AP3K Brand System

## Brand foundation

**Positioning:** AP3K turns Instagram attention into immediate, measurable action.

**Brand promise:** A new comment should never become a missed opportunity.

**Primary line:** **Turn attention into action.**

**Product descriptor:** Instagram comment and DM automation.

**Personality:** Fast, clear, capable, energetic and controlled. AP3K is never robotic, noisy, childish or filled with empty “AI magic” claims.

## Logo idea

The AP3K Signal Mark is a custom letter **A** built around a forward arrow. The A identifies the brand; the arrow represents the movement from comment to reply, DM, link and lead.

Always write the brand as **AP3K**. Do not use AP3k, Ap3k or ap3k in display copy.

### Clear space and minimum size

Keep clear space equal to at least one quarter of the mark’s width around every logo. Do not display the mark below 20 px digitally. Use the horizontal wordmark above 96 px wide; below that size, use the mark alone.

Never stretch, rotate, outline, recolor with unapproved colors, add effects, place the gradient mark over a busy image, or type AP3K inside a generic square.

## Color system

| Role | Name | Hex | Usage |
|---|---|---:|---|
| Primary | Signal Violet | `#6D28D9` | Logo, primary controls, focus and brand recognition |
| Primary light | Pulse Purple | `#8B5CF6` | Gradients, illustration and hover states |
| Energy | Motion Pink | `#EC4899` | Selective emphasis and campaign energy |
| Action | Action Coral | `#FF6B35` | CTAs, directional highlights and conversion moments |
| Dark neutral | Deep Ink | `#0B1020` | Dark surfaces, copy and premium contrast |
| Light neutral | Cloud | `#F6F5FB` | Page backgrounds and quiet sections |
| Surface | White | `#FFFFFF` | Cards and clean space |
| Success | Signal Mint | `#34D399` | Delivery, connection and success states only |

### Primary gradient

`linear-gradient(135deg, #6D28D9 0%, #8B5CF6 46%, #EC4899 74%, #FF6B35 100%)`

Use the full gradient only for the mark, main CTA, important highlights and branded campaign art. Most product surfaces should remain neutral so the brand color keeps its power.

## Typography

**Primary:** Plus Jakarta Sans.

- Display: 800–900 weight, tight tracking (`-0.04em` to `-0.055em`)
- Headings: 700–800 weight
- Body: 400–600 weight with generous line-height
- UI labels: 700 weight
- Kicker labels: uppercase, 800–900 weight, wide tracking

Avoid thin display typography, condensed novelty fonts and mixing several font families.

## Iconography and imagery

Use rounded, confident line icons with consistent stroke weight. Icons explain actions; they do not decorate every empty space.

Brand imagery should show a clear transformation: comment → trigger → response → lead. Use deep violet environments, luminous directional lines, coral action cues and clean interface forms. Avoid generic robots, floating brains, random sparkles, fake testimonials and unrelated stock photos.

## Voice

Write in plain, active language.

- Prefer: “Reply while interest is still fresh.”
- Avoid: “Leverage next-generation AI-powered engagement solutions.”
- Prefer: “Choose a trigger. Write the reply. Activate.”
- Avoid: vague claims such as “Revolutionize your social presence.”

AP3K copy should be direct, useful and confident. Explain what happens, when it happens and what the user controls.

## Core messaging

**Homepage headline:** Your Instagram just got smarter.

**Support line:** Turn comments into instant replies, DMs and trackable leads—without living in your inbox.

**Primary CTA:** Start free

**Secondary CTA:** See how it works

**Campaign message:** Comment → Reply → DM → Lead.

## Accessibility

Use white text on Signal Violet or Deep Ink. Use Deep Ink text on Cloud or white. Action Coral is an accent and must not be used for small body text on white. All interactive elements must retain visible focus states and at least WCAG AA contrast.
