# AP3K content and admin contrast release — 24 September 2026

## Theme repair
The admin route re-exports pages from ap3k-admin-v2. The previous theme update did not cover those page bodies, leaving light-on-light text. The shared table also used unsupported Tailwind opacity suffixes (/82, /88 and /78), leaving its light background active in dark mode. This release uses semantic table surfaces, pairs legacy text colors, fixes remaining arbitrary opacity syntax and uses readable muted tokens across admin screens. Billing, permissions and message-delivery behavior are unchanged. Dark remains the default for visitors without a saved theme.

## Editorial scope
100 new English articles across ten distinct groups, plus seven commercial pages and an index at /resources/instagram-growth-library. Articles are source-backed published entries in the existing editorial system: owners can edit or unpublish them in Content studio. The library uses the merged published inventory, so hidden articles disappear and edited titles are respected. No database migration is required.

These are concise workflow guides, not promises of ranking, invented customer results or undocumented features. Scheduling and ad topics explicitly identify the separate tools and systems involved. New English-only paths use English canonical/alternate URLs instead of claiming translations. Existing localized content remains localized.
